# Контракт модели хамелеона (chameleon.glb)

Этот документ описывает всё, на что опирается код сайта. Если модель меняется, сначала обновляется этот файл.

## Файл

- Исходник: `chameleon.glb` (~14.5 МБ, glTF 2.0, текстуры PNG без сжатия).
- Перед использованием на сайте файл нужно оптимизировать (см. раздел «Оптимизация»). Цель — до 3 МБ.
- Рабочий Blender-проект: `chameleon_07_clips.blend`.

## Система координат и размеры

- Y вверх (стандарт glTF). Морда смотрит в **+Z**, хвост уходит в **−Z**.
- Масштаб 1 единица = 1 м: длина от носа до кончика хвоста ~1.9, высота ~0.8.
- Лапы стоят на плоскости Y = 0, модель отцентрована по X.
- На сцене модель масштабируется под раскладку (ожидаемо ~0.3–0.5 от исходного размера).

## Объекты

| Узел | Что это |
|---|---|
| `Chameleon_Rig` | скелет, корень иерархии |
| `Chameleon` (mesh `Chameleon_Body`) | тело, skinned mesh, материал `Chameleon_Skin` |
| `Chameleon_Eyes` (mesh `Chameleon_Eyes`) | два глазных яблока, skinned на `Eye_L` / `Eye_R` (вес 1.0), материал `Chameleon_Eye` |

Morph targets нет. Рта, челюсти и языка нет (сознательно убраны).

## Скелет (35 костей)

```
Hips
├── Spine → Chest
│          ├── HeadLook (не деформирует, только для кода) → Head
│          │                                              └── Eye_L, Eye_R
│          ├── FrontLeg_Shoulder_L → FrontLeg_Upper_L → FrontLeg_Lower_L → FrontLeg_Hand_L
│          └── FrontLeg_Shoulder_R → FrontLeg_Upper_R → FrontLeg_Lower_R → FrontLeg_Hand_R
├── HindLeg_Hip_L → HindLeg_Thigh_L → HindLeg_Shin_L → HindLeg_Foot_L
├── HindLeg_Hip_R → HindLeg_Thigh_R → HindLeg_Shin_R → HindLeg_Foot_R
└── Tail_01 → Tail_02 → … → Tail_12
```

## Владение костями (главное правило)

Каждый кадр порядок строго такой: **сначала `mixer.update(delta)`, потом код.** Иначе клип перезапишет то, что сделал код.

| Кость | Кто управляет | Как код применяет |
|---|---|---|
| `HeadLook` | только код | абсолютное вращение (клипы её не трогают) |
| `Eye_L`, `Eye_R` | клип `eyes_look` как фон + код | код плавно смешивает позу клипа с позой «смотреть на цель» по весу внимания (0 = только клип, 1 = только код) |
| `Tail_01…12` | код (на лендинге) | **Отступление от исходного контракта:** на лендинге хвост задаётся кодом от rest-ориентации костей, а не поверх клипа: спираль вверх (положительный поворот вокруг локальной X) + виляние вокруг Z. Клип `walk` по хвосту перезаписывается. Так поза детерминирована и не ломается при загрузке. Если нужна анимация хвоста из клипа, вернуть аддитивный режим |
| остальные | клипы | код не трогает |

## Оси (проверено в Blender, при первом запуске сверить в Three.js)

У всех костей локальная ось **Y направлена вдоль кости**.

- **`HeadLook`**: в покое смотрит прямо вперёд. Поворот «влево-вправо» — вокруг локальной **Z**, «вверх-вниз» — вокруг локальной **X**. Пределы: yaw ±30°, pitch ±15°.
- **`Eye_L`, `Eye_R`**: точка вращения — центр глазного яблока. Локальная **+Y = направление взгляда в покое** (в стороны и чуть вперёд, как у настоящего хамелеона). Поворот считать как кватернион «от направления покоя к направлению на цель» в пространстве родителя (`Head`), с ограничением угла ±40°. Глаз крутится внутри неподвижного гнезда, кожа вокруг не деформируется.
- **`Tail_01…12`**: закрутка вниз в спираль = **отрицательный** поворот вокруг локальной **X**, у каждой следующей кости чуть сильнее. Покачивание из стороны в сторону — вокруг локальной **Z**.

## Клипы анимаций

| Имя | Длительность | Цикл | Кости | Назначение |
|---|---|---|---|---|
| `walk` | 2.0 с (60 кадров, 30 fps) | да, бесшовный | 31: таз, позвоночник, лапы, хвост | ходьба **на месте** с закрученным хвостом. За один цикл модель проходит **0.12 м** (в единицах исходной модели) — код двигает хамелеона вдоль ветки синхронно с фазой клипа |
| `eyes_look` | 6.0 с (180 кадров) | да | 2: `Eye_L`, `Eye_R` | глаза независимо осматриваются скачками; фоновое поведение, когда пользователь ничего не делает |

`walk` на сайте не проигрывается по времени, а **управляется скроллом**: `action.paused = true`, `action.time = phase * duration`.

Клипов `idle_breath` и `grip` пока нет (можно добавить позже).

## Материалы и UV

**`Chameleon_Skin`**: baseColor (2048², с запечённым затенением в складках), normal map (2048², рельеф чешуи), roughness 0.55, metallic 0.

- `TEXCOORD_0` — основная развёртка текстур.
- `TEXCOORD_1` (`uv1` в Three.js) — **BodyAxis**: `u` = 0 на кончике носа → 1 на кончике хвоста; лапы получают значение точки крепления. `v` = 0.5 (не используется). По нему шейдер делает волну смены цвета от головы к хвосту.

**`Chameleon_Eye`**: текстура радужки 1024² + normal map, roughness 0.22.

- UV глаза — проекция вдоль взгляда: **центр зрачка = (0.5, 0.5)**.
- Радиус зрачка в UV ≈ 0.10, внешний край радужки ≈ 0.47.
- Расширение зрачка в шейдере: радиально сжимать UV к центру внутри радиуса радужки (волокна двигаются вместе со зрачком).

## Оптимизация (выполнить в проекте)

```bash
npx @gltf-transform/cli optimize chameleon.glb public/models/chameleon.glb \
  --compress meshopt --texture-compress webp --simplify false
```

Проверить флаги через `npx @gltf-transform/cli optimize --help`: важно **не** включать упрощение сетки и не допустить удаления узла `HeadLook` (он не деформирует, но обязателен). После оптимизации проверить, что в файле 35 костей и 2 анимации. Для meshopt в `useGLTF` из drei декодер подключается автоматически.

## Что не входит в модель (делает код)

- поворот головы к курсору / к кнопке CTA (`HeadLook`);
- слежение глазами за курсором и «чтение» текста (`Eye_L` / `Eye_R`);
- закрутка хвоста по прогрессу скролла и реакция на скорость скролла (`Tail_*`, аддитивно);
- смена цвета волной (шейдер по `uv1`);
- размер зрачка (шейдер радужки);
- перемещение вдоль ветки (корневой объект, синхронно с фазой `walk`).
